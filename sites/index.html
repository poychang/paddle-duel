HOW TO PLAY

規則簡單。
下一球，不簡單。

上下移動球拍，把球打回去。球越來越快，勝負就在一次回擊之間。

01

同一台電腦，兩位玩家

玩家一使用 W / S，玩家二使用 ↑ / ↓。不需另外註冊遊戲帳戶。

02

一個人，也能來一場

單人模式提供 Easy、Medium、Hard 三種 AI 難度。相同的球場規則，不同的對手節奏。

03

需要休息，隨時暫停

按 Esc 暫停。切換到其他視窗也會自動暫停，回來後再選擇繼續。

RELEASE STATUS

為 Windows 桌面而生。

目標平台為 Windows 10 22H2 與 Windows 11。目前仍在開發與封裝驗證階段，尚未提供正式下載或開放 Store 購買。

每日免費 3 次；完成一場比賽才計次。額度以 UTC 日界線計算。付費遊玩次數功能仍待 Microsoft Store 驗證，售價與供應狀態以未來 Store 顯示為準。
