## 2. 裝置上的遊戲資料

遊戲不要求另行註冊玩家帳戶。目前沒有第三方廣告、使用行為分析 SDK 或由我們營運的遊戲資料上傳服務，不讀取通訊錄、相片、麥克風、攝影機或精確地理位置。

為運作遊戲，裝置上會保存下列資料：

| 資料                                           | 用途與保存方式                                                                                                                                              |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 免費比賽隨機識別碼、UTC 額度日期、最後觀察日期 | 計算每日免費額度、防止重複扣次與處理時鐘回撥。查詢額度時，移除早於最後觀察日期減 400 天的比賽紀錄，保留邊界當日與更新紀錄及最後觀察日期；不是背景定時刪除。 |
| 視窗位置、尺寸、全螢幕選擇                     | 還原視窗設定，保留至被取代或清除。視窗位置是桌面座標，不是地理位置。                                                                                        |
| 待履行商品識別碼、數量、交易履行 tracking ID   | 避免付費比賽重複扣次並支援失敗重試。Store 確認成功或已履行後移除；未成功紀錄沒有固定到期時間。                                                              |
| 損毀的免費額度隔離檔                           | 避免繼續使用無效資料；沒有自動到期清除機制。                                                                                                                |

免費額度與視窗設定不由遊戲上傳給我們或 Microsoft Store。按鍵與比賽狀態用於即時遊戲操作，不保存為逐次操作分析紀錄。交易回報另依下一節處理。

本機資料由裝置保存，我們無法透過遊戲遠端存取或代為清除。遊戲目前沒有內建資料匯出或清除介面；清除本機資料可能影響設定、額度與尚未完成的交易重試，不會刪除 Microsoft 管理的帳戶、訂單或餘額。解除安裝是否清除全部本機檔案，仍須以正式封裝行為為準。

## 3. Microsoft Store 與其他服務

付款與付費餘額由 Microsoft Store 管理。遊戲透過 Store API 查詢商品名稱、價格與餘額，要求購買，接收操作結果，並在付費比賽完成後傳送商品識別碼、消耗數量與 tracking ID。tracking ID 用於交易履行及防止重複扣次，不用於廣告追蹤。

遊戲程式不要求或讀取 Microsoft 帳戶密碼、信用卡號、禮品卡號或付款安全碼。Microsoft 自行處理其服務涉及的帳戶、付款與購買資料，請參閱 [Microsoft 隱私權聲明](https://privacy.microsoft.com/privacystatement)。Microsoft 帳戶及訂單資料的查詢、管理或刪除，請使用 Microsoft 的管道；我們不另建帳戶或跨裝置餘額帳本。

Windows、Microsoft Store、電子郵件及政策頁面託管服務本身的資料處理，另依各服務政策與使用者設定辦理。

本官網為靜態頁面，未加入分析追蹤、廣告、表單或自行設定的 cookies。網站由 GitHub Pages 託管；GitHub 可能為提供服務與安全用途處理訪客 IP 位址等連線資訊，詳見 [GitHub 隱私權聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

## 4. 主動聯絡與資料請求

若你主動寄信，我們會透過電子郵件服務取得寄件地址、內容及附件，僅用於處理該次聯絡、相關爭議或法律要求，並依上述目的與適用法律所需期間保存。請勿寄送密碼、驗證碼、付款卡號、禮品卡碼或與問題無關的個人資料。

對我們實際持有的個人資料，如需提出查詢、更正、刪除或其他適用法律下的請求，可使用上述信箱。處理範圍依適用法律與實際持有的資料而定；不表示我們可代為操作你的裝置、Microsoft 帳戶或第三方系統。

## 5. 政策變更

資料處理方式變更時，本政策及生效日期會相應更新；如法律要求額外告知，依其規定辦理。本政策不排除適用法律保障的權利或強制義務。
