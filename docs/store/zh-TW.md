## Description

```text
簡單的來回，緊張的對決。再來一局！

Paddle Duel 是一款受早期電子街機啟發的極簡桌球遊戲。移動球拍、回擊來球，率先取得 11 分即可獲勝。

你可以挑戰具有三種難度的電腦對手，也可以和朋友共用一把鍵盤，在同一台 Windows 電腦上進行雙人對戰。

遊戲特色：
• 單人模式提供簡單、普通與困難三種難度。
• 本機雙人對戰，在同一畫面上一較高下。
• 簡潔的黑白視覺風格。
• 可調整視窗大小，也能自行切換全螢幕。
• 鍵盤操作：W／S 與方向鍵 ↑／↓。

遊戲可免費下載，每個 UTC 日提供 3 次免費完整比賽。你也可以透過選用的遊戲內購買功能取得額外遊玩次數。系統優先使用免費次數，再使用已購買的次數；比賽結束前離開不會消耗次數。

本機雙人模式需要兩位玩家使用同一台電腦，不支援線上多人連線。

Paddle Duel 為獨立創作，與 Atari 無關，亦未獲其背書。
```
