## Description

```text
A simple rally. A close match. One more game.

Paddle Duel is a minimalist table-tennis game inspired by early electronic arcade games. Move your paddle, return the ball, and be the first to reach 11 points.

Play solo against a computer opponent with three difficulty levels, or challenge a friend on the same Windows PC using one keyboard.

Features:
• Single-player mode with Easy, Medium, and Hard difficulty.
• Local two-player competitive play on a shared screen.
• Clean black-and-white visuals.
• Resizable window and optional full-screen mode.
• Keyboard controls: W/S and the Up/Down arrow keys.

Free to download, with 3 free completed matches per UTC day. Additional play packs are available through optional in-game purchases. Free plays are used before purchased plays. Leaving a match before it finishes does not consume a play.

Local two-player play requires both players to use the same PC. Online multiplayer is not supported.

Paddle Duel is an independent creation and is not affiliated with or endorsed by Atari.
```
