## 2. 遊戲在裝置上處理的資料

### 免費遊玩額度

遊戲保存已完成免費比賽的隨機識別碼、額度所屬 UTC 日期，以及最後觀察到的最大 UTC 日期，用於計算每日免費次數、防止重複扣次與處理時鐘回撥。

這些紀錄保存在裝置上；目前程式不將免費比賽紀錄上傳至我們的伺服器或 Microsoft Store，也不以它建立玩家個人檔案。

### 視窗設定與遊戲輸入

遊戲在裝置上保存視窗位置、尺寸與全螢幕選擇，以便下次還原。視窗位置是桌面座標，不是 GPS 或地理位置。

遊戲會即時處理玩家操作、比賽狀態與 AI 難度選擇；目前程式沒有將逐次按鍵或完整比賽過程保存為分析紀錄，也沒有將其傳送至我們的伺服器。

## 3. Microsoft Store 購買與消耗型商品

付費購買由 Microsoft Store 處理，付費遊玩餘額由 Microsoft 管理。遊戲會透過 Windows Store API：

- 查詢附加商品識別碼、商品名稱與格式化價格。
- 查詢可用付費餘額並要求開啟 Store 購買流程。
- 接收購買、餘額查詢與消耗回報的狀態。
- 在付費比賽完成後，傳送商品識別碼、消耗數量及履行追蹤識別碼（tracking ID），回報消耗。

履行 tracking ID 用於避免相同交易重複扣次與支援重試，不是廣告識別碼。為避免網路或程序中斷遺失回報，遊戲會先將商品識別碼、數量與 tracking ID 存入本機待履行紀錄，再與 Microsoft Store 通訊。

我們的遊戲程式不要求或讀取 Microsoft 帳戶密碼、信用卡號、禮品卡號或付款安全碼。這不表示交易沒有資料處理：Microsoft 會依其服務處理帳戶、付款、購買及餘額資訊，相關內容請參閱 [Microsoft 隱私權聲明](https://privacy.microsoft.com/privacystatement)。

遊戲本身不設立另行註冊的玩家帳戶，也不自行建立跨裝置付費餘額帳本。Store 帳戶與訂單資料的管理須透過 Microsoft 提供的管道進行。

## 4. 分析、廣告與其他資料用途

目前遊戲沒有整合第三方廣告 SDK、使用行為分析 SDK 或由我們營運的遙測上傳服務；不為廣告目的使用免費額度紀錄或履行 tracking ID。

目前程式不讀取通訊錄、相片、麥克風、攝影機或精確地理位置。Windows 與 Microsoft Store 可能依使用者設定及其政策進行自身的診斷或服務資料處理，這與遊戲自行上傳遙測資料不同。

## 5. 聯絡支援時提供的資料

若你透過電子郵件聯絡我們，我們會取得你主動提供的電子郵件地址、信件內容與附件，用於回覆問題、排查故障及處理隱私權請求。郵件也會由所使用的電子郵件服務處理。

請勿傳送帳戶密碼、驗證碼、完整付款卡號、禮品卡碼或其他不必要的敏感資訊。提供截圖或錯誤資訊時，請先遮蔽與問題無關的個人資料。

## 6. 保存期間與資料清除

- **免費額度紀錄：** 遊戲在後續讀取額度時，依最後觀察到的最大 UTC 日期裁剪歷史，移除早於該日期減 400 天的比賽紀錄，保留邊界當日與更新的紀錄。最後觀察日期仍保留以處理時鐘回撥。這不是背景定時刪除；若不再啟動遊戲或查詢額度，檔案不會自行按日清理。
- **視窗設定：** 保留至被後續設定取代，或該本機資料被清除。
- **待履行交易：** 收到 Store 成功或已履行回應後移除該筆本機紀錄。失敗紀錄保留供之後重試；目前沒有固定到期刪除時間。
- **損毀檔案：** 無法讀取或無效的免費額度檔可能被隔離保存，以避免繼續使用損毀資料；隔離檔目前沒有自動到期清除機制。
- **支援信件：** 本草稿建議僅於回覆、處理爭議或適用法令所需期間保存，目的結束且無保留必要後刪除。實際郵件保存、備份及刪除流程須由產品擁有者在發布前確認。

目前遊戲沒有內建的資料匯出或清除介面。你可以透過上述信箱詢問本機資料的確認與清除方式；我們不會因此取得遠端存取你裝置的權限。

在清除或重設遊戲資料前，請先確認沒有尚待處理的付費消耗回報；直接刪除待履行紀錄可能中斷重試。刪除本機檔案不會刪除 Microsoft Store 帳戶、訂單或其管理的付費餘額。正式封裝的解除安裝／重設行為仍需驗證，本文不承諾解除安裝會清除所有資料。
